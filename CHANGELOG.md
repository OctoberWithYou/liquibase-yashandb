## [1.0.0] — 2026-06-04

### Added

- Initial release of the YashanDB Liquibase connector.
- `YashanDbDatabase` — `AbstractJdbcDatabase` implementation for YashanDB:
  - Product name detection (`jdbc:yasdb://...`, product name containing `yashan`).
  - Default port `1688`, driver `com.yashandb.jdbc.Driver`.
  - Oracle-compatible schema/catalog handling (`supportsSchemas() = false`).
  - Two-layer `isSystemObject()` filter:
    - schema level (`CTXSYS`, `XDB`, `YMP_DEFAULT`)
    - name-prefix level (`BIN$`, `AUD$`, `WRH$_`, `SCHEDULER$_`, … + `…$` suffix rule)
  - Oracle-style date literals (`TO_DATE`, `TO_TIMESTAMP`).
  - `GENERATED BY DEFAULT AS IDENTITY` auto-increment for YashanDB ≥ 23.4.2.
  - Reserved-word list aligned with Oracle/YashanDB keywords.
  - 64-byte identifier length cap (`PK_<TABLE>`).
- SQL generators:
  - `YashanDbCreateDatabaseChangeLogTableGenerator` / `YashanDbCreateDatabaseChangeLogLockTableGenerator`
    (use `TIMESTAMP` for `DATEEXECUTED` / `LOCKGRANTED`).
  - `YashanDbSetNullableGenerator` — emits `ALTER TABLE … MODIFY col [CONSTRAINT …] [NOT] NULL`.
  - `YashanDbModifyDataTypeGenerator` — emits `ALTER TABLE … MODIFY col <newType>`.
- Snapshot generators:
  - `YashanDbTableSnapshotGenerator` — filters system tables during bulk enumeration.
  - `YashanDbIgnoreViewSnapshotGenerator` — disables view enumeration.
- Standard `META-INF/services` SPI registration for `Database`, `SqlGenerator` and
  `SnapshotGenerator`.
- Maven `pom.xml` with `liquibase-core` and `yashandb-jdbc` as `provided` dependencies.
- GitHub Actions CI workflow (build + test on JDK 8/11/17).
