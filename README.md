# Liquibase Connector for YashanDB

[![CI](https://github.com/yashandb/liquibase-yashandb/actions/workflows/ci.yml/badge.svg)](https://github.com/yashandb/liquibase-yashandb/actions/workflows/ci.yml)
[![Maven Central](https://img.shields.io/maven-central/v/com.yashandb/liquibase-yashandb.svg?label=Maven%20Central)](https://search.maven.org/artifact/com.yashandb/liquibase-yashandb)
[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)

The official [Liquibase](https://www.liquibase.org/) connector for [YashanDB](https://www.yashandb.com/).
It plugs Liquibase's `Database`, `SqlGenerator`, and `SnapshotGenerator` extension points
with implementations that understand YashanDB's SQL dialect and system objects, so your
projects can run `liquibase update` / `liquibase snapshot` against a YashanDB instance
out of the box.

Inspired by the official [liquibase-oracle](https://github.com/liquibase/liquibase-oracle)
and [liquibase-mysql](https://github.com/liquibase/liquibase-mysql) connectors.

## Features

- `YashanDbDatabase` — `AbstractJdbcDatabase` implementation tuned for YashanDB
  (Oracle-compatible syntax, custom `isSystemObject()` filter, version detection,
  `GENERATED BY DEFAULT AS IDENTITY` auto-increment for v23.4.2+).
- SQL generators that emit YashanDB-compatible DDL for:
  - `DATABASECHANGELOG` / `DATABASECHANGELOGLOCK` tables
  - `SetNullable` (`ALTER TABLE ... MODIFY col [NOT] NULL`)
  - `ModifyDataType` (`ALTER TABLE ... MODIFY col <newType>`)
- Snapshot generators:
  - `YashanDbTableSnapshotGenerator` — filters out the YashanDB system dictionaries
    (`OBJ$`, `COL$`, `TAB$`, `BIN$...`, `WRH$_...`, etc.) so snapshots stay clean.
  - `YashanDbIgnoreViewSnapshotGenerator` — disables view enumeration.
- Zero configuration: classes are discovered automatically via standard
  `META-INF/services` SPI registration.

## Quick Start

Add a single dependency to your project's `pom.xml`:

```xml
<dependency>
    <groupId>com.yashandb</groupId>
    <artifactId>liquibase-yashandb</artifactId>
    <version>1.0.0</version>
</dependency>
```

Liquibase will pick up `YashanDbDatabase` through SPI and start recognising
`jdbc:yasdb://...` URLs. No extra configuration required.

### Example `liquibase.properties`

```properties
driver: com.yashandb.jdbc.Driver
url:    jdbc:yasdb://127.0.0.1:1688
username: sys
password: your_password
changeLogFile: db/changelog/db.changelog-master.xml
```

### Example changelog (`db.changelog-master.xml`)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<databaseChangeLog
    xmlns="http://www.liquibase.org/xml/ns/dbchangelog"
    xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
    xsi:schemaLocation="http://www.liquibase.org/xml/ns/dbchangelog
        http://www.liquibase.org/xml/ns/dbchangelog/dbchangelog-4.9.xsd">

    <changeSet id="1" author="demo">
        <createTable tableName="example_table">
            <column name="id" type="int" autoIncrement="true">
                <constraints primaryKey="true" nullable="false"/>
            </column>
            <column name="name" type="varchar(255)">
                <constraints nullable="false"/>
            </column>
        </createTable>
    </changeSet>

    <changeSet id="2" author="demo">
        <modifyDataType tableName="example_table" columnName="name" newDataType="varchar(3000)"/>
    </changeSet>

    <changeSet id="3" author="demo">
        <addNotNullConstraint tableName="example_table" columnName="name" columnDataType="varchar(3000)"/>
    </changeSet>
</databaseChangeLog>
```

Run:

```bash
liquibase update
```

## Requirements

| Component | Minimum version |
|-----------|-----------------|
| Java      | 8+              |
| Liquibase | 4.17.1+         |
| YashanDB JDBC driver | 1.9.24+ |

`liquibase-core` and `yashandb-jdbc` are declared with `provided` scope, so the
consuming project (or the `liquibase` CLI classpath) is expected to bring them in.

## Building from Source

```bash
mvn clean install
```

The YashanDB JDBC driver is not on Maven Central. Install it into your local
repository first, e.g.:

```bash
mvn install:install-file \
    -Dfile=yashandb-jdbc-1.9.24.jar \
    -DgroupId=com.yashandb.jdbc \
    -DartifactId=yashandb-jdbc \
    -Dversion=1.9.24 \
    -Dpackaging=jar
```

## How It Works

Liquibase uses Java's `ServiceLoader` to discover extensions. When the connector
JAR is on the classpath, Liquibase reads `META-INF/services/liquibase.database.Database`
and finds `YashanDbDatabase`. During connection detection,
`YashanDbDatabase.isCorrectDatabaseImplementation()` checks whether the JDBC
product name contains `yashan` and activates the connector.

From that point on, every DDL statement emitted by Liquibase goes through the
YashanDB-specific generators, and every snapshot goes through the YashanDB-specific
snapshot filters — producing SQL and metadata that actually work against YashanDB.
